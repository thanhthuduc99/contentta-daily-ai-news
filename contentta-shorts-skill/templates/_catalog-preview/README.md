# _catalog-preview — 8 style mẫu standalone (xem nhanh để chọn hướng)

File HTML **độc lập** (mở thẳng browser, không cần hyperframes) — mỗi cái loop ~3s, có KEYWORDS ở comment đầu. Dùng để team/khách **duyệt phong cách** trước khi build, KHÔNG phải composition để chèn vào project (composition thật nằm ở `../scene-patterns/`).

```bash
npx serve contentta-shorts-skill/templates/_catalog-preview -p 8088 -n
# mở http://localhost:8088/<file>.html
```

| File | Hướng | Use-case |
|---|---|---|
| 01-hook-cosmic | Cosmic | câu hook mở đầu (orbital + word slam + flare) |
| 02-bignumber-cosmic | Cosmic | nhấn 1 con số (particle converge + tremor) |
| 03-cards-cosmic | Cosmic | liệt kê 3 ý (card cascade + SVG icon) |
| 05-cta-supernova | Cosmic | CTA cuối (burst + pill) |
| 07-divider-editorial | Editorial | chuyển chương (số stroke + hairline) |
| 08-comparison-editorial | Editorial | so sánh trước/sau (strike + accent) |
| 09-stat-editorial | Editorial | stat % count-up serif |
| 10-outro-hybrid | Hybrid | outro brand (orbital → wordmark) |

> 2 hướng chủ đạo: **COSMIC** (vũ trụ xoay vòng) và **EDITORIAL** (tạp chí serif). Trộn được trong cùng 1 video.
